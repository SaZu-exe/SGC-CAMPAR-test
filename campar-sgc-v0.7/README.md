# CAMPAR SGC Digital v0.7

Versión que recupera funciones esenciales perdidas durante la depuración visual.

## Recuperaciones principales
- Botón **+ Nueva OC** en el módulo Órdenes.
- Posibilidad de **Abrir OC**, **Ampliar OC** y **Reabrir OC** con historial de cambios.
- Posibilidad de **Abrir inspección** existente desde el módulo Inspecciones.
- Desde Inventario, los lotes en **Limpios** mantienen la acción **Inspeccionar lote** para crear una nueva inspección.

## Estructura
- `index.html`: interfaz completa con estilos y lógica embebidos.
- `assets/logo-campar.png`: logotipo CAMPAR.
- `docs/`: acceso rápido al Manual de Calidad y Compendio Maestro.
